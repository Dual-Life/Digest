# CLAUDE.md — Digest

## About

Digest is a Perl core module providing a unified interface for message digest algorithms.
It dispatches `Digest->new("Algorithm")` to the appropriate `Digest::*` implementation module.

- **Upstream**: `gisle/digest` (Gisle Aas)
- **Fork**: `Dual-Life/Digest`
- **CPAN**: https://metacpan.org/pod/Digest

## Repository layout

```
lib/Digest.pm          # Main dispatch module
lib/Digest/base.pm     # Base class for digest implementations
lib/Digest/file.pm     # File digest convenience functions
digest-bench           # Benchmarking script (not installed)
t/                     # Test suite
t/lib/Digest/Dummy.pm  # Mock module for testing
Makefile.PL            # ExtUtils::MakeMaker build
cpanfile               # Dependency declaration
```

## Build & test

```bash
perl Makefile.PL
make
make test              # Must pass before committing
```

Tests run via `Test::More` and use `File::Temp` for temp files.

## Key conventions

- **Formatting**: Perltidy with `.perltidyrc` (4-space indent, 400 char line limit)
- **Strict/warnings**: All `.pm` and `.t` files use `use strict; use warnings;`
- **Filehandles**: Lexical (`my $fh`), never barewords. Use 3-arg `open`.
- **MANIFEST**: Generated by `make manifest` — do not manually sort or edit
- **README**: Generated from POD — do not edit directly
- **Versions**: Bumped by the maintainer during release. Do not change `$VERSION` or `Changes`.

## Testing guidelines

- Use `Digest::Dummy` (in `t/lib/`) or in-memory mock packages for testing dispatch logic
- Real algorithm modules (`Digest::MD5`, etc.) may not be available in all test environments
- Temporary files must use `File::Temp` with `UNLINK => 1`

## What NOT to change

- `Changes` — release changelog maintained by the human
- `$VERSION` values — set during CPAN releases
- `MANIFEST` — regenerated, not hand-edited
- `README` — generated from POD via `pod2markdown`
